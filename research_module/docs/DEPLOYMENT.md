# 部署

## 本地单用户

`python manage.py serve`。默认只监听127.0.0.1。管理员 token 每次随机产生，或用环境变量指定。`--private-mode` 只能在127.0.0.1运行；不要用隧道、共享代理或转发将该模式发布出去。校内信息的使用范围由原数据条件和你的授权决定。

## Docker / 小规模公开试点

先生成至少24位随机令牌，例如：

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

把输出设为 `RESEARCHSPACE_ADMIN_TOKEN`，或放入只在本机保存的 `.env` 给 Compose 使用。然后 `docker compose up --build -d`。不要把真实环境变量写入代码。容器中以普通用户运行，数据库保存在命名卷。

反向代理示例：

```caddyfile
research.example.org {
  reverse_proxy 127.0.0.1:8000
}
```

替换为自己的域名并按实际代理软件申请证书。管理端应限制访问；增加请求速率、上传大小与并发连接控制。若使用转发头，应自行设计可信代理名单；当前应用按连接IP限流，在反向代理后可能把所有用户计为同一IP。应用不接受浏览器任意跨站POST。所有公开 API 不返回私有数据。

此服务是轻量验证实现，Python标准库HTTP服务不等同生产应用服务器。高流量部署需要：成熟ASGI/WSGI层、异步队列、独立采集worker、任务锁、账户鉴权、服务端用户数据隔离、备份与监控。本包没有把这些尚未实现的能力包装成已完成。

## 备份与更新

停止服务后复制 `var/`，或使用 SQLite backup API 导出一致性快照。不要在运行时只复制主db而漏掉WAL文件。数据库含私有数据时备份按私有资料保管。

抓取定时任务应按来源服务规则安排离峰执行。NIH建议不超过每秒一请求，本包间隔至少1.1秒。官方大批量任务另有建议时段，应遵守其文档。

进程重启会把原queued/running任务标记为interrupted；已提交的来源游标仍可继续。CLI与HTTP不要同时针对同一数据库同一来源运行，当前没有分布式任务锁。

## 故障排查

- 页面打不开：确认Python版本至少3.11、终端服务仍运行、端口未被占用。可用 `--port 8080`。
- 查不到SRT：默认模式排除私有数据；使用 `--private-mode`，并确认导入与启动使用同一 `--db`。
- 没有“已确认开放”：这是证据不足或核对过期的真实显示，不是故障。
- 推荐为空：检查筛选；学校冲突默认隐藏，切换对应勾选项可查看原因。
- 采集失败：检查报告 errors、网络/代理、robots规则与页面结构。不要靠关闭安全校验解决。
- 网络需要代理：设置 `HTTPS_PROXY` 或 `RESEARCHSPACE_HTTPS_PROXY`；使用受信任的出口代理。
- 画像消失：清理浏览器站点数据会清除IndexedDB，事先通过界面导出JSON。
