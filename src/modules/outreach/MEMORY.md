## 已落地

1. 完整 React 工作区与独立 DefaultPanel、授权弹窗、草稿编辑器。
2. 基于实际 HostApi 的目录搜索、深链接、AI 代理及账号内存储；无虚构 HostApi 扩展签名。
3. 姓名/机构核对、来源与查阅日期、用户勾选事实、阅读层次、纯函数内容计划与多语言模板。
4. 中英德日法结构模板；自由文本原语言保留并明确提示。
5. AI 完整资料预览、逐次许可、严格 JSON 与引用检查、最多一次修复、请求超时/取消、迟到响应丢弃。
6. 项目资格、开放状态、联系政策独立检查；详细交接显式绑定宿主画像版本，基础 SDK 模式提供官方来源人工核对。
7. 草稿编辑、复制、TXT 下载、本地保存/读取/重命名/删除、手动联系状态、旧画像提示；所有存储走宿主作用域。
8. 可替换搜索、抓取、调查、计划、生成、验证、存储；同源 JSON 公开检索适配器与替换示例。
9. 关键逻辑、DOM 操作与宿主集成验证；实际结果及浏览器覆盖见 `docs/VERIFICATION.md`。

## 仍取决于外部配置的能力

- 真实导师/项目数据由已安装 Provider 提供；未安装可手动填公开资料。
- 实际模型调用需要主程序的可信 AI 代理和服务端密钥；本次使用模拟响应验证协议，不声称已实测收费模型质量。
- 全网搜索需要独立公开检索网关；本包提供客户端 Search/Fetch 端口和 HTTP 适配器，不包含服务端、付费密钥或自动网页身份认证。
- 不自动发送、不群发、不推断招生名额或成功概率；自动事实检查只作初筛，用户仍需审阅最终语义与翻译。

## 后续修改纪律

从本包当前代码和测试出发，不再依据旧路径 `<temporary-development-path>` 猜测已交付状态。先读当前宿主冻结 SDK；不要修改它或引入独立账户/数据库。任何联系规则变化要覆盖状态、资格、路由、来源和画像版本的组合；任何远程调用要保持当次预览、许可与取消处理。测试命令、版本和未经真实服务验证的部分须如实记录。
