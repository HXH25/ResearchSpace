## 规则与异常覆盖

- 五种语言模板；零小时投入和空可选画像；最长允许研究介绍；不将技能选择变成成果。
- 当前招募与个人资格分离；门户限定/禁止联系；错误联系人和 route；缺失官方证据；过去截止时间和不明时区；演示项目禁止正式申请。
- 交接所属账号、画像版本、项目、目的、有效期；真实 legacy 字段的外层版本封装；缺失交接 status 不自动变为开放。
- 手动官方联系确认绑定当次目的，切换目的后不能复用原许可。
- JSON 重复 key、额外字段、非法语言、未知事实 ID、数值捏造、假附件、未经确认的阅读升级和 HTML。
- AI 未授权零调用；最多一次修复；修复不回传失败文本；网络异常不重试；45 秒超时；取消与过期结果丢弃。
- 存储所有者检查、格式损坏时保留旧数据、同一仓储并发保存串行化。
- 部分公开查询失败保留成功结果，同名候选不合并，不向搜索发送学生资料，网关 URL 和结果结构验证。
